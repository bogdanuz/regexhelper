## Текущее состояние

- **Приложение:** конвертер триггеров в regex с поддержкой простых и связанных триггеров, параметров (любой символ `\w`, латиница/кириллица, транслитерация, склонения с авто/точными окончаниями, опциональные символы), соединителей, истории. Работает в браузере без сборки.
- **Структура:** миграция на `core/`, `shared/`, `tools/converter/`, `assets/` завершена. Старый код и скрипты миграции удалены. **Аудит кода завершён** (2026-02-21): удалены неиспользуемые модули, актуализированы тесты, обновлена документация.
- **UI конвертера:** простые и связанные триггеры разнесены в **переключаемую панель** (верхняя часть страницы). По умолчанию активна панель «Связанные триггеры»; переключение на «Простые триггеры» — клик по заголовку панели. Каждый режим конвертируется отдельно. Кнопка «Очистить панель» корректно переключается между режимами. **Панель результата** растянута на всю ширину и расположена под переключаемой панелью; кнопки: «Конвертировать», «Копировать», **«В тестер»**, **«В визуализатор»**, **компактная «Очистить»** (справа).
- **Тесты:** браузерная страница **tests/test.html** (5 вкладок, в т.ч. визуализатор с тестами diagram-block, overflow, экспорт «Скачать» is-open); Node тесты: p0-logic (141), converter-reference (61), visualizer (19), texthelper (60), **tester (69)**, editor (28) — все проходят. **Все тесты проходят на 100%.** Запуск: `npm run test` (Node) или `npm run test:browser` (Playwright); единый скрипт **tests/run-tests.mjs**. Браузерные тесты (test.html): 275+ в конвертере, 192+ в визуализаторе; добавлены тесты для ручного редактора и истории (сохранение в историю type manual, карточка «Из редактора», setEditorContent замена, «В редактор» с карточки), а также для «Инвертировать выделенное» в режиме сырого инвертирования (без автозамен, проверка отсутствия `пул[ьъ]т`). Все тесты актуализированы под новую архитектуру, включая авто-удвоение букв, опциональные символы, расширенные склонения, разделение ед./мн. числа, корректную группировку скобок и исправление инвертации групп (2026-02-21) и ручного редактора (2026-03-03).
- **Визуализатор:** интегрирован regexper-static (бандл в **assets/libs/regexper/**). Блок diagram-block (панель всегда внизу), зум/пан через transform без скроллбара (как Miro/Figma), fit to view при первой отрисовке, центрирование больших и маленьких диаграмм. Документация: **docs/visualizer/**.
- **Регистр:** инструмент конвертера регистра текста (tools/case/). Модальное окно, открывается по кнопке «Регистр» в навигации. Документация: **docs/case/ARCHITECTURE.md**.
- **Тестер:** инструмент проверки regex на тестовой строке (tools/tester/). Секция в index.html между Визуализатором и Историей. Flavor Python (emulated). По умолчанию флаги g, m, u; \b с кириллицей через эмуляцию Unicode-границ. **Реал-тайм подсветка ошибок** в поле regex (debounce 180 ms): скобки, ведущий/конечный \|, \|\|, лишняя `}`, плюс позиция из сообщения движка; маппинг позиций из обработанного паттерна в исходный. Поддерживается пара выражений **TRUE/FALSE**: TRUE — что ловить, FALSE — что исключить; совпадения FALSE не подсвечиваются в тексте, но выводятся в отдельном блоке «Совпадения FALSE (исключения)», а результат TRUE автоматически очищается от пересекающихся с ними совпадений. При выделении текста в поле «Тестовый текст» в заголовке блока «Совпадения» отображается строка статистики выделения (**«Символов всего / Без пробелов / Пробелов»**), которая автоматически скрывается при отсутствии выделения. Флаг u добавляется только при включённом чекбоксе «unicode». Документация: **docs/tester/ARCHITECTURE.md**.
- **Документация:** архитектура, структура, статус, навигация по docs. WIKI полностью переписана (2026-02-21) — простое руководство пользователя.
- **Уведомление об обновлениях:** автоматическая проверка новой версии (раз в час). Если сайт обновился пока пользователь на странице — появляется тост «Доступно обновление». GitHub Action автоматически обновляет `version.json` при push в main.

## Стабильно ✅

Все компоненты протестированы и работают корректно.

### Конвертация
- Простые триггеры: textarea → regex с альтернацией `(слово1|слово2|...)`
- Связанные триггеры: визуальный конструктор → regex с соединителями

### Параметры (все работают)
| Параметр | Regex | Статус |
|----------|-------|--------|
| Лат/Кир | `[аa]`, `[оo]` | ✅ |
| Транслит | `[рr][оo][бb][лl]` | ✅ |
| Склонения (авто) | `слов(о\|а\|у)` — сущ., прил., прич. | ✅ |
| Склонения (точные) | `корень(ок1\|ок2)` | ✅ |
| Любой символ (\w) | `корень\w{1,10}` | ✅ |
| Границы слова (\b) | `\bслово`, `слово\b`, `\bслово\b` — выбор позиции | ✅ |
| Пробел после (\s) | `слово\s` | ✅ |
| Опциональные | `пасс?ивный` | ✅ |

### Склонения: расширенная поддержка (2026-02-21)
| Часть речи | Пример | Статус |
|------------|--------|--------|
| Существительные (ед.ч.) | дом → дом(а\|у\|ом\|е) | ✅ |
| Существительные (мн.ч.) | книги → книг(и\|ам\|ами\|ах) | ✅ |
| Прилагательные | красивый → красив(ый\|ого\|ому...) | ✅ |
| Причастия (-нный, -тый, -мый, -щий) | написанный → написанн(ый\|ого...) | ✅ |
| Супплетивные формы мн.ч. | дети → дет(и\|ей\|ям\|ьми\|ях) | ✅ |
| Глаголы | ❌ (используйте `\w` или точные окончания) | — |
| Краткие прилагательные | ❌ (используйте точные окончания) | — |

**Важно:** Ед. и мн. число склоняются **отдельно**. Если ввести «ребёнок» — получите только формы ед. числа (ребёнка, ребёнку...), без «дети». Для мн. числа введите отдельный триггер «дети».

### Автозамены
- `ё → [её]` ✅
- `ь → [ьъ]` ✅
- `ъ → [ъь]` ✅
- Авто-удвоения: `аллея → алл?ея` ✅

### Соединители (все паттерны верны)
| Режим | Паттерн | Статус |
|-------|---------|--------|
| Альтернация | `\|` | ✅ |
| Любое расстояние | `[\s\S]+` | ✅ |
| Абзац | `.+` | ✅ |
| Строка | `[^\n]+` | ✅ |
| Своё значение | `.{min,max}` | ✅ |

### Ручной редактор (tools/editor/)
- Поле ввода regex, кнопки параметров/соединителей (вставка в позицию курсора), Копировать, В визуализатор, В тестер, Проверить, **Сохранить в историю**, Очистить ✅
- **Инвертировать выделенное:** кнопка в шапке (рядом с подсказкой), видна только при выделении в поле; по нажатию выделенный фрагмент парсится как regex **в сыром режиме ручного редактора** (без автозамен и глобальной нормализации), порядок элементов инвертируется, результат собирается из исходных фрагментов и вставляется в конец через `|` (меняются только порядок и соединители, сами триггеры/группы не переписываются) ✅
- **Сохранить в историю:** сохраняет текущее выражение в общую историю с типом `manual` (только при непустом поле); тост при пустом поле и при успехе ✅
- Приём из панели результата и из истории: кнопка «В редактор» в панели результата и на **каждой карточке истории** (панель, модалка «Вся история», модалка «Подробнее») — полная замена содержимого редактора и скролл к секции редактора; при клике из модалки полной истории модалка закрывается ✅
