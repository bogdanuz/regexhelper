![RegexHelper](assets/images/logo.png)

Инструмент для создания, визуализации и тестирования регулярных выражений. Превращает список слов в готовое регулярное выражение с учётом падежей, транслитерации и т.п. Работает в браузере без сборки и серверной части.

**[🚀 Открыть приложение](https://bogdanuz.github.io/regexhelper/)**

---

## 📖 Быстрый старт

1. Откройте [приложение](https://bogdanuz.github.io/regexhelper/)
2. Введите слова в поле ввода (каждое с новой строки)
3. Выберите нужные параметры (склонения, транслитерация и др.)
4. Нажмите **Конвертировать** — готовое регулярное выражение появится в поле результата
5. Скопируйте результат или отправьте в **Ручной редактор**, **Тестер** или **Визуализатор**

## 🔧 Конвертер триггеров

### Простые триггеры

Превращает список слов в регулярное выражение с альтернацией. Каждое слово — отдельный вариант для поиска.

**Ввод:**
```
кошка
собака
хомяк
```

**Результат:**
```regex
(кошка|собака|хомяк)
```

Такой regex найдёт любое из этих слов в тексте.

---

### Связанные триггеры

Визуальный конструктор для создания сложных паттернов. Позволяет искать последовательности слов, которые идут друг за другом в тексте с определённым расстоянием между ними.

**Пример задачи:** найти текст, где слово "купить" встречается рядом со словом "оптом".

**Как это работает:**

1. **Добавляете триггеры** — слова или фразы, которые нужно найти
2. **Настраиваете соединители** — расстояние между словами:
   - *Любое расстояние* — слова в любом месте текста
   - *В пределах абзаца* — слова в одном абзаце
   - *В пределах строки* — слова на одной строке
   - *Точное расстояние* — указать количество символов между словами
3. **Группируете триггеры** — объединяете несколько слов в группу (любое из них сработает)
4. **Перетаскиваете** (drag & drop) — меняете порядок элементов

**Пример:**

```
[купить] ---(в пределах строки)--- [оптом]
```

**Результат:**
```regex
купить[^\n]+оптом
```

Найдёт: "купить товары оптом", "купить со склада оптом" и т.д.

## ⚙️ Параметры преобразования

Параметры применяются к каждому слову и расширяют возможности поиска:

| Параметр | Что делает | Пример |
|----------|------------|--------|
| **Лат/Кир** | Учитывает похожие буквы разных алфавитов (a↔а, o↔о) | `apple` → `[аa]pple` |
| **Транслитерация** | Генерирует все варианты написания слова | `roblox` → `[рr][оo][бb][лl][оo](кс\|x)` |
| **Склонения** | Добавляет падежные формы (сущ., прил., причастия, мн. число) | `документ` → `документ(а\|у\|ом\|е)` |
| **Любой символ (\w)** | Добавляет символы после слова | `доставк` → `доставк\w{1,3}` |
| **Границы слова (\b)** | Ищет только целые слова | `кот` → `\bкот\b` (не найдёт "котлета") |
| **Пробел после (\s)** | Требует пробел после слова | `цена` → `цена\s` |
| **Опциональные** | Учитывает возможные опечатки (удвоенные буквы) | `аллея` → `алл?ея` |

## 🛠 Дополнительные инструменты

### Ручной редактор

Панель для ручного редактирования регулярных выражений. Позволяет дорабатывать результат конвертера или собирать regex с нуля, используя справа готовые кнопки для вставки типовых фрагментов (`\w`, `\b`, `\s`, соединители `|`, `[\\s\\S]+`, `.{0,10}` и т.д.). Есть кнопка **«Проверить»** — подсвечивает синтаксические ошибки прямо в поле и помогает быстрее находить проблемные места; повторное нажатие выключает подсветку.

### Визуализатор

Строит railroad-диаграмму регулярного выражения — наглядная схема структуры regex. После «Визуализировать» диаграмма сразу вписывается в поле и центрируется (fit to view). Зум к курсору (Ctrl+колёсико) и к центру (кнопки −/+), пан перетаскиванием — без скроллбара, как в Miro/Figma. Экспорт в SVG или PNG.

### Тестер

Проверяет регулярное выражение на тестовом тексте в реальном времени. Совпадения подсвечиваются. Поддерживает флаги: global, multiline, case-insensitive и другие.

### Текстовый помощник

Набор утилит для работы с текстом: столбец ↔ строка, удаление дубликатов и пустых строк, добавление обёртки (префикс/суффикс), удаление пробелов, изменение регистра (ВЕРХНИЙ, нижний, Каждое Слово, иНВЕРТИРОВАННЫЙ).

### История

Автоматически сохраняет последние конвертации (до 300 записей, хранятся 7 дней). Можно быстро вернуться к предыдущему результату.

## 💻 Запуск локально

Приложение не требует сборки — просто откройте в браузере:

```bash
git clone https://github.com/bogdanuz/regexhelper.git
cd regexhelper
```

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
npx serve .
# Откройте http://localhost:3000
```
